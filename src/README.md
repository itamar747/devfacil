# DevFácil – Plataforma de Estudos de Programação

## Sobre o projeto

O DevFácil é uma plataforma educacional desenvolvida para ajudar pessoas que desejam iniciar seus estudos na área de programação.

O site apresenta cursos de HTML5, CSS3, JavaScript e React, permitindo que os usuários conheçam as tecnologias e organizem seus cursos favoritos.

## Tecnologias utilizadas

- React
- JavaScript
- CSS3
- Vite
- LocalStorage

## Funcionalidades

- Navegação dinâmica no formato SPA.
- Apresentação de cursos de programação.
- Sistema para adicionar e remover favoritos.
- Salvamento dos favoritos no navegador.
- Página com informações sobre o projeto.
- Formulário interativo de contato.
- Interface responsiva.

## Framework escolhido

Foi escolhido o React por facilitar o desenvolvimento de interfaces dinâmicas por meio de componentes reutilizáveis e gerenciamento de estados.

Além disso, o React permite desenvolver aplicações SPA, proporcionando uma navegação mais rápida e organizada.

## Como executar o projeto

1. Clone o repositório.
2. Entre na pasta do projeto.
3. Instale as dependências:

```bash
npm install
```

4. Execute o projeto:

```bash
npm run dev
```

5. Abra o endereço indicado no terminal.
